# Код-ревью лабораторной работы № 3

## Применённый кодстайл

- Длина строк — не более 90 символов.
- Для вложенности используются отступы в 4 пробела.
- Названия функций и переменных оформлены в `snake_case`, константы — в
  `SCREAMING_SNAKE_CASE`.
- У модулей и публичных функций есть docstrings в Google Style.
- Аннотации типов указаны для функций и структур данных.
- Нет голого `except:` и изменяемых значений по умолчанию.
- Дополнительно создан `documentation.xml` с XML-описанием модулей, функций,
  параметров, возвращаемых значений и исключений там, где они предусмотрены.

## Итоги повторной проверки

1. **Страны и города.** Город сопоставляется стране; при отсутствии города выводится
   сообщение из условия.
2. **Пиццерия.** Повторные заказы одной пиццы суммируются; покупатели и пиццы
   выводятся по алфавиту. Лишний вывод общего количества пицц отсутствует.
3. **«Угадайка».** Ответ «Да» сужает множество пересечением, ответ «Нет» удаляет
   перечисленные числа; команда «Помогите!» завершает диалог и печатает кандидатов.
4. **Генеалогическое дерево.** Высоты вычисляются рекурсивно и кешируются, вывод
   отсортирован по имени. В случае N = 1 условие не содержит имя человека, поэтому
   программа сообщает, что высоту такого элемента определить невозможно.
5. **Английские слова.** Проверяются количество строк и пустые записи; сравнение
   переводов не учитывает регистр. Итоговая оценка теперь выводится.

## Допущение в задании 5

В условии сказано выставить оценку, но пороги оценивания не даны. Чтобы программа
выдавала оценку, в ней условно принята шкала: 90–100% — 5; 75–89,9% — 4;
50–74,9% — 3; менее 50% — 2. Эти пороги нужно заменить, если преподаватель использует
другую шкалу.
